Models & project notes

Transliteration changes script; it does not translate meaning. Common English words use a limited preservation list. Review names, ambiguous spellings and generated rewrites before using them.

Conversion uses AI4Bharat's Hindi model. Phrasing and translation use BharatGen Param1, running locally in a quantized format. Your writing stays on this computer. Successful results are cached in memory until the app closes. No API key or hosted inference quota is required.

Evaluation includes 40 authored application cases, an attributed Aksharantar Hindi test sample and separate Param1 writing tests. See README.md for model provenance and measured limitations.
